# AppNote — VSTEP notes on a Huawei Watch GT 6 Pro

A HarmonyOS **lite wearable** app (JS) for the Huawei Watch GT 6 Pro that shows VSTEP exam prep
content on the wrist, plus an Android companion app that can push data to the watch.

```
watch/    DevEco Studio project (lite wearable, FA model, JS) — bundle com.datnt.gtpush.watch
phone/    Android app "AppNote" (Kotlin, Compose, Wear Engine SDK) — package com.datnt.gtpush
scripts/  import-vstep.py · deploy-watch.sh · make-icon.py · make-skill-icons.py
signing/  local signing material (git-ignored, see signing/README.md)
```

## Watch app
Home (clock + 4 skill tiles) → exam list (Đề 7/12/17) → table of contents → detail.

| Skill | Content |
|---|---|
| Đọc / Nghe | the 20 original questions per exam + the document's answer |
| Viết | email task + sample email, essay question + sample essay |
| Nói | Part 1 Q&A, Part 2 task summary + answer, Part 3 topic + talk, follow-up Q&A |

Colours: question/task blue, answer/sample green, template frame red.
Content is generated by `scripts/import-vstep.py` from the "Ôn thi VSTEP" web app into
`watch/entry/src/main/js/MainAbility/common/content.js`.

## Common commands
```bash
python3 scripts/import-vstep.py [URL]      # pull the VSTEP data and regenerate content.js
./scripts/deploy-watch.sh                  # build + sign + push to the phone + install via DevEco Assistant
~/.venvs/adcreative/bin/python scripts/make-icon.py   # watch + phone launcher icons
cd phone && ./gradlew :app:assembleDebug   # phone app
```

Install path for the watch: signed debug HAP → `/sdcard/haps/` on the phone → HUAWEI DevEco Assistant →
Huawei Health → watch (GT watches have no `hdc`).

## Phone app
Pushes `{"title","value","sub","text"}` (≤ 1 KB) to the watch through Wear Engine P2P and, as a fallback that
needs no Wear Engine approval, as an Android notification that Huawei Health mirrors to the watch.
A local HTTP endpoint lets a Mac push over USB:
```bash
adb forward tcp:8765 tcp:8765
curl -X POST localhost:8765/push -d '{"title":"Ghi chú","text":"..."}'
```
Wear Engine needs the AppGallery Connect App ID in `phone/gradle.properties` (`gtpush.huaweiAppId`) and an
approved Wear Engine application.
